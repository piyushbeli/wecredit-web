# Auth Images

Place the authentication screen illustrations here from Figma:

- `phone-step-illustration.png` - Illustration for the phone input screen
- `otp-step-illustration.png` - Illustration for the OTP verification screen

## Usage

These images are used in the `GradientHeader` component with `variant="with-illustration"`.

Until the images are added, a placeholder will be displayed with a dashed border.
